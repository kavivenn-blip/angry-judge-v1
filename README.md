# Angry Judge: The Short Rant Contest

A program that writes one short, funny rant about an everyday
annoyance to `/output/entry.txt`: 47 minutes on hold with a company
that keeps insisting your call is important to it.

## Run

```sh
python3 main.py
```

Writes one UTF-8 text of 324 characters to `/output/entry.txt`.
Python 3 standard library only — no network, no dependencies,
no randomness: every run writes the same bytes.
